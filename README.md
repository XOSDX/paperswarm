# PaperSwarm: Autonomous ArXiv-to-Production Microservice Engine
Built for the UC Berkeley x Google DeepMind Hackathon (Antigravity CLI Track)

PaperSwarm uses Google Gemini 2.5 and Antigravity CLI (`/swarm`) to convert static academic research papers on arXiv into live, unit-tested, containerized FastAPI + React/Tailwind microservices deployed on Google Cloud Run.
